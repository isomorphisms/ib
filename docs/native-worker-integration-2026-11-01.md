# Native source-to-reader implementation checkpoint

Campaign SUN IB-TABP10-READER-COMPLETE-01 remains **INCOMPLETE**. The following
implementation connects previously separate owners. It is not an executed
end-to-end transaction or a TAB_P10 qualification.

The checked `NativeReader` Activity submits an opaque checked HTTP(S) request to
`ReaderBridge`. The narrow JNI broker owns the Android thread, navigation lease,
random source identity, app-private ingress capability and canonical userspace
Arena. An authorized Shizuku shell user service receives that capability only
after fresh permission, server identity and epoch checks. Its source-bound
runtime catalog selects the actual Grease engine, checked ICU Main DEX and ICU
JNI library. Grease supervises `app_process`, passes the URI as one argument and
streams the ICU frame to the app-owned PFD. There is no alternate network client.

The private SDK Binder parses a bounded, descriptor-free request before any
effect. Its memory anchor retains the native session while remote references
exist. The native publisher admits and commits using the maintained Arena v2
owner. The independent source owner reopens and checks the immutable source,
length, digest and generation, then the source reader checks the transferred
read-only stream again. The checked Idriç callback performs admission,
extraction and measured Prepaint layout before acknowledging its last-good
source index. That index contains identities only, never document bytes.

Greedy and squared reflow are available through a visible selector. The viewport
and an immutable Paint snapshot supply actual Android measurements. A retained
source can be reopened after layout without reacquisition; corruption falls back
to the previous index. Interrupted unselected staging directories are preserved.
This is ordinary userspace Arena, not kernel appendfat. The initial 4 MiB Arena
currently refuses further publication when full; safe capacity growth remains
unfinished.
