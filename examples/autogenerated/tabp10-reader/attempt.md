# TAB_P10 reader integration

The requested result is the installed checked Idriç Activity → private Binder
capability → authorized Grease/ICU worker → canonical Arena v2 → independently
verified source → extraction/Prepaint/reflow → native document view.

## Types and effects

- Existing `HtmlEvidence`, `HtmlPrepaintResult`, `PrepaintRevision`,
  `PrepaintLayout`, `SourceLine`, `DurableIdentity` and history entries remain
  owned by their maintained modules.
- The Android view is a projection of an admitted committed source. Raw Intent
  text is never evidence of source admission.
- A navigation request has a browser generation and attempt identity. Retained
  source generations remain immutable when Back/Forward selects them.
- An acquisition failure, stale callback, decoder failure or renderer death
  must preserve the last committed source and history.
- Source offsets are decoded Unicode code points. Android selection offsets
  are UTF-16 units; neither is an HTML byte offset.
- Idriç owns validation, extraction, source-linked layout and navigation;
  Grease owns worker/process orchestration; native code owns Android Binder,
  descriptors, platform view/clipboard operations and filesystem guarantees.

## Backend and qualification

Consume merged android-NDK `6ab4818219efa7ea5eda137ca6b76976eb2a4d42`.
First compile the unchanged NativeSourceProjection, SearchIntentRequest and
NativeReader against that backend. Use its explicit managed-export boundary
for source lists/records, while retaining the separate Activity contract.
No handwritten candidate DEX or substitute application language is permitted.

`prepare.grease` builds the pinned backend and retains compiler/runtime inputs.
`verify.grease` compiles the maintained consumers and integration, independently
decodes DEX, compares deterministic output and records explicit failure stages.
Compiled mutation controls and ART execution are separate stages.

`verify-native.grease` checks bounded private streaming, permanent ingress
revocation and retained source/navigation identities. Its two compiled mutants
must fail the corresponding assertion, not merely exit for an unrelated error.
`verify-native-canonical.grease` repeats retained-source readback and the
generation mutant using actual pinned canonical userspace appends and ai-ci's
independent source oracle. Response observations in these native host tests are
explicit fixtures. They do not prove an Android Binder transaction or fetching.
