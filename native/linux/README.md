# Linux platform boundary

This initial C ABI is stateless and Linux x86-64 only. It rejects __ANDROID__,
even for Android x86-64. The Idriç module IB.Linux.Platform owns the conversions
between semantic Text/Number values and bounded C values. Embedded NUL text is
refused before a borrowed C-string call; no normalization or decoding occurs.

The current functions qualify ABI, pointer width and UTF-8 FFI transport. They
are not a window, renderer, storage adapter or browser application. All browser
objects remain in the existing Idriç modules. Future native facilities must
extend this narrow boundary without introducing frontend-owned browser state.

The checking recipe lives in isomorphisms/kitchen tasks/ib-desktop/3.grease and
the independent oracle in isomorphisms/ai-ci
examples/autogenerated/ib-shared-core/NativeFoundationOracle.idric. The new
consumer compile/link stage selects ICK, with source pins and native runtime
hashes recorded in its receipt. Idriç generation explicitly selects the maintained
Chez backend; RefC and handwritten generated-C substitutes are excluded.

The generated ib-linux-foundation-check is a packaged Chez program using a
native Linux Chez executable and an ICK-built shared library. It is not named
ib-desktop and cannot satisfy the graphical desktop milestone.
