# Native Idriç reader

The application path is checked Idriç -> direct DEX -> Android framework views.
`examples/autogenerated/native-reader/NativeReader.idric` owns the temporary
text/action adapter; XML owns its resources. The checked Activity emitter calls
the framework superclass before the create export and forwards the Activity
receiver and clicked view to the checked action export.

The reader wraps supplied text in a selectable native TextView. It accepts
Android plain-text shares and an explicit pasted-text input. The Sources
button shows/hides that input; Read copies its exact text into the reader.
This small view does not own browser state or interpret HTML as a document.

The legacy Java/Gradle prepaint and WebView trees and their build workflows
are removed on this migration line. Their historical source remains at IB
41d4cae9c15e42d3b0b4ed4ed957ba86a7ac396a. No Java fallback is selected.
Existing Idriç semantics and Grease acquisition remain in place.

## Incomplete migration

This is a partial migration. The native reader is not a replacement claim for
retained-source projection, image blocks, acquisition, Binder workers,
Longview sessions or durable navigation.

The historical `_builtin.NIL` and `Prelude.Types.fastUnpack` failures belong to
earlier compiler pins and remain in their dated attempt records. The maintained
gitlink builds on merged android-NDK
`6ab4818219efa7ea5eda137ca6b76976eb2a4d42`, with the reusable Text numeric cast
repair at `b2720c422f957bd53f3e5e0895e38b4289735ad8`. The tablet qualification compiles the
unchanged source-title consumer, HTML/Prepaint/reflow integration, search
projection and Activity with that backend. It keeps command, pure-export and
framework Activity contracts separate. No historical pass qualifies this new
integration.

The [current integration ledger](../docs/tabp10-reader-integration.md) records
actual results and remaining product gaps. Committed-source readback and
private ingress are not yet connected to this Activity's lifecycle, browser
history or view. The checked source projection does not grant authority to
receipt-shaped Intent text. Keep this line draft until the real application
pipeline and independent physical acceptance pass.
