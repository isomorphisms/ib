# IB test cases

These are plain-English behavior cases. They are meant to survive implementation changes and later be translated into executable tests where useful.

Each case records:

- **Negative user story** — what must not happen.
- **Desired behavior** — what IB should do instead.
- **Inspector evidence** — what the inspector should expose so a bad ranking, search, or storage decision can be explained.

The first cases cover omnibox suggestions/interior search and reclaimable speed-up storage.
