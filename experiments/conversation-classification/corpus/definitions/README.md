# Category and projection definitions

Concept categories and filing destinations are persistent definitions, not
names inferred from a fitted model.  Each definition must state its axis,
meaning, inclusion and exclusion criteria, adjacent categories, version, and
creation provenance.  The full category inventory must be induced and reviewed
from the acquired corpus; no title-only category list is promoted here.

Changing a definition creates a new definition version.  Feature vectors remain
reusable when their input grammar is unchanged; only affected category models
need retraining.  Filing policy is a separate versioned projection over accepted
concept memberships and evidence.
