# Evaluation and failures

Primary reports require screened conversation bodies, reviewed concept labels,
explicit negatives where available, duplicate-grouped held-out evaluation, and
a separate chronological evaluation.  Reports must include category support,
macro/micro measures, false-positive and false-negative rates, multilabel
examples, margin distributions, filing coverage/misfile/review rates, stability,
correction persistence, and measured incremental cost.

Title-only or synthetic runs are pipeline diagnostics and must never be
presented as evidence about the primary task.
